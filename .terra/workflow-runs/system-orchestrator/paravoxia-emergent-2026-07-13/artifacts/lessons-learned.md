# Lessons Learned

- Planet identity must travel through every generator, cache, water, spawn, and
  render consumer. Seed equality is never canonical identity.
- A Story checkpoint must preserve physical phase and ownership. Persisting the
  milestone without ship/system pose can manufacture evidence on reload.
- World-local receipts and actor-global milestones need an explicit reconciliation
  boundary for partial saves and reconnects.
- Creative contracts become useful only when signed anchors drive runtime state
  and drift is a build failure; documents alone cannot enforce cohesion.
- Automated movie mode should use the same public physical/transaction APIs as a
  player. Rescue and timeout paths may keep a screening moving but cannot count
  as narrative acceptance.
- Browser proof catches profile and composition failures that large unit suites
  cannot. Capture failure must not erase semantic telemetry from later cases.
- Preserve publish authority as a separate decision. A green implementation run
  does not imply human taste approval or authorization to deploy.
