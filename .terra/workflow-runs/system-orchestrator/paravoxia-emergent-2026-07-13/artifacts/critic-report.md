Disposition: implementation candidate passes; release taste gates remain separate.

The independent static review originally found seven blocking seams. Each was
reproduced against source and repaired before the implementation verification:

1. Movie mode stopped at `ch4-vigil` — fixed with registered physical/runtime
   bindings through the second hearth; no emergent milestone injection counts as
   acceptance.
2. Tidegarden direct boot used seed-only volcanic generation — fixed by keying
   generation and every live consumer by canonical `worldId`; browser evidence is
   now verdant with no exposed lava or basalt.
3. Connected co-op could not address p1 or persist the arc — fixed with canonical
   world routing, authenticated same-actor transactions, accepted structure
   evidence, and reconnect projection.
4. Replay retained p1 Habitat truth while deleting actor receipts — fixed by
   clearing both Story worlds and suppressing the stale unmount autosave.
5. Reload after crossing fabricated a surface landing — fixed by restoring a
   validated atmospheric pose or safe descent fallback without landing evidence.
6. Ship location was unwired and Return to Site targeted p0 — fixed with durable
   surface/atmosphere/local-space poses and Tidegarden return ownership.
7. The signed AV rail had no runtime consumer — fixed with a SHA-locked generator,
   typed semantic anchor bridge, live FOV/score/PostFX consumers, telemetry, and
   reset coverage.

The follow-up review found and repaired three more high-severity seams: the
Habitat restore revision loop after Core placement, a Low/Potato clock freeze
that prevented natural night rest, and a whole-rail pond-entry race between dry
step assist and fixed-step dive intent. It also hardened partial Habitat saves
with same-actor receipt reconstruction, actor-owned ACK/reconnect continuity,
and server-owned foundation, enclosure, conflict, and nighttime evidence.

The final cold-run campaign found and repaired four additional runtime seams:

1. Unsupported feet-only water contact with a dry eye and exhausted jetpack
   produced no meaningful swim blend, deadlocking wet-bank egress. A bounded
   shallow unsupported swim factor now preserves physical stroke authority.
2. A cached cross-face `unreachable` result with no waypoint survived after the
   body settled from unsupported to supported. The cache now invalidates on
   material displacement or unsupported-to-supported contact and preserves the
   local wet-egress leg before replanning onward travel.
3. High-frequency local pose publication could still feed a new React array to
   avatar/minimap subscribers every frame and recurse to maximum update depth.
   Frame-coalesced external-store notifications now expose referentially stable
   full and remote-only snapshots, so local-only traffic does not rerender
   consumers that discard it.
4. `EfficientScene` still routed continuous frame positions through React state,
   while render-created debug adapters crossed a passive-effect boundary. A live
   position mailbox and stable debug callbacks remove that scene-position /
   passive-loop path.
